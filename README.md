# 💪 FitApp – Personal Fitness Tracker

FitApp is a Flutter-based fitness application that helps users maintain a healthy lifestyle by providing workout plans, exercise categories, and favorite exercises. Users can also create their own personalized workout routines.

---

# 📱 Features

## 🔐 Authentication

- User Registration
- User Login
- Secure Authentication
- User Profile

---

## 👤 Profile

- View User Name
- View Email Address
- Simple & Clean Profile UI

---

## 🏋️ Exercise Library

- Full Body Exercises
- Chest Exercises
- Back Exercises
- Shoulder Exercises
- Arm Exercises
- Leg Exercises
- Core Exercises

---

## ❤️ Favorites

- Add Exercise to Favorites
- Remove Exercise from Favorites
- View All Favorite Exercises

---

## 📋 Custom Workout Plans

- Create Personal Workout Plans
- Add Exercises to Workout Plan
- Remove Exercises
- Organize Daily Workout Routine

# 📂 Installation

Clone the repository

```bash
git clone https://github.com/Raza373316/fitapp.git
```

Install dependencies

```bash
flutter pub get
```

Run the application

```bash
flutter run
```
